**纵向数据是什么意思。**

同一批人被持续随访：用某人较早时点的资料，研究其较晚时点的健康结果。不同年份抽取不同的人调查，不自动构成个人层面的纵向数据。

NHEFS 原队列为参加 1971—1975 年 NHANES I 检查的人员，随后进行多轮随访。这里下载的是 NHEFS 随访公开文件，不等于已经取得 NHANES I 所有基线检查、营养和化验原始文件。如果选定特征依赖那些模块，还需要继续补取。

**如何读取与准备模型。**

- 原始 .txt 是固定宽度格式，不是逗号分隔 CSV。需要按 documentation/*.inputs.labels.txt 中的 SAS INPUT 位置与宽度读取。
- 人员 ID 必须保留为字符串。不同文件的 ID 名称、位置不同，例如 SEQNUM1、SEQNO、HANESEQ、SEQNUM；追踪文件的 ID 在第 12—16 列，死亡记录的 ID 在第 3—7 列，不能全部取前五列。
- 1982 访谈包含重复记录卡片标识，应按发布方布局解释。
- 已在后续访谈字段说明中确认糖尿病、高血压、卒中及心脏病相关问题和部分年份字段。它们是候选信息，尚未完成病种标签编码核对与清洗。
- 建模需重建预测起点的疾病史、后续事件和随访状态。未知、拒答、失访、死亡或回顾性报告不能直接记为阴性。
- 如果研究老人，应按所选预测起点的年龄筛选，不能将 14,407 人全部称为老年样本。
- 可先评估 1987→1992 的约五年随访任务，是否采用该窗口取决于日期、病史和有效事件的审计结果。

**适用范围。**

这是较早年代的美国人群数据，具有历史时期、医疗条件与人群差异。可用于学习纵向数据处理和开发研究原型；在中国社区老人的疾病风险估计仍需要匹配人群的独立评价。当前网站原有 ICU 模型未因下载本数据而自动变更。
