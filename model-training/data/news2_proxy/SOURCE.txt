The split CSVs contain an older auxiliary target that is no longer used. The current target is in future_five_score_labels.csv and is built from observed 24-48h median vitals. It indicates whether the five-component aggregate reaches 5, retaining only labels certain despite missing components. It is not a same-time full NEWS2 score, a diagnosis, or a clinically validated healthy/unhealthy label.
