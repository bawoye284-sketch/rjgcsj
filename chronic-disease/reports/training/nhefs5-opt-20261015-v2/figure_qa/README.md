# 优化实验图表核验

本版本30张正式单绘图区图由Python/matplotlib从真实保存的预测生成，包含每病两种模型的混淆矩阵，以及ROC、PR、校准和开发集阈值图。PNG、PDF、SVG、600dpi TIFF与曲线源数据均保留。

- 源码检查21项通过，无警告或失败；见source_audit.json。
- 最终30份PDF通过碰撞检查和5pt字体下限检查，逐文件SHA-256及退出码见summary.json。
- 每份正式图只有一个定量绘图区，无多面板对齐要求；alignment.json已记录不适用。
- 已逐张检查五病种总览中的全部30张图，标题、图例、轴标签、方向和混淆矩阵数字可读，无截断或相互遮挡。总览PNG仅用于核验，汇报使用各病figures/下正式图片。
- 校准图采用全部评价预测、5个等频分箱与观察比例95% Wilson区间，坐标范围包含全部估计和区间。
- ROC和PR是固定模型的单次曲线，不是多折均值；标量指标的500次参与者重抽样区间单独报告。阈值图只用开发集折外预测。
- 未更改原版报告或权重；新旧人员、标签和原有特征逐条一致。模型和接口一致性核验见上级verification.json。

原留出集曾被查看，本轮属于探索性比较。图表核验不代表模型预测有效；高血压默认阈值召回率为0等不利结果完整保留，不能仅凭较高准确率宣称改进。
