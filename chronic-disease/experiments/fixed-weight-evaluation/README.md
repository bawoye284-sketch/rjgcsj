# 现有权重的训练集与测试集评估

本目录仅评估现有模型，不重新训练、不改动权重文件、不切换网站模型。

对每个疾病模型，依据原始训练成员清单，将实际用于拟合的全部记录标为训练集，将未用于该模型拟合的剩余记录标为测试集。所有原队列记录均保留在其中一个集合；两者在同一病种内按参与者互斥。五个病种是分别训练的二分类模型，不是共同拟合的多任务模型，各自的成员划分分别核对。

权重来源为历史实验的默认版本，由文件路径、版本、阈值和 SHA256 固定。原实验目录和过程记录保留，本目录不改写历史设置或旧报告。当前报告的测试指标只使用实际未参加该模型训练的样本重新计算。测试数据此前曾在开发过程中被查看，因此属于现有队列内部评估，不宣称全新外部验证。

从 `rjgcsj` 运行：

```powershell
& .\chronic-disease\.venv\Scripts\python.exe -B .\chronic-disease\experiments\fixed-weight-evaluation\evaluate.py --name nhefs5-fixed-20261017
```

每次使用新名称，不覆盖已有运行记录。数据、预测、指标和图表放在 `runs/<版本>/` 下的 `data/`、`reports/` 中；`model_references.json` 记录五个原权重的位置与摘要，不复制、不修改权重。

## 图表约定

图表回答“现有权重在真实训练成员与剩余测试成员上的表现有何不同”。使用 Python / Matplotlib；只沿用项目的配色、中文字体、布局与导出样式，按新的真实集合重新实现数据映射。训练指标为拟合回代值，测试指标来自未参加拟合的记录，分别标注，不混合计算。

训练／测试人数图说明样本基础，准确率与平衡准确率对比展示拟合差距，测试热力图、ROC、PR、逐病种混淆矩阵描述测试表现。指标零值照实保留。每病仅有少量测试事件，95%区间以500次参与者 bootstrap 计算，另存JSON；曲线及柱图展示点估计，不表示重复训练均值。

每图一个绘图区；常规图7.2×4.8英寸、混淆矩阵3.5×3.8英寸。优先微软雅黑，至少8pt，导出300dpi PNG与文字可编辑的PDF、SVG。中文标题、坐标、图例与中文文件名统一保存在 `reports/模型性能图表/`，QA记录另放 `figure_qa/`。课程汇报无需TIFF与600dpi导出。可通过 `--qa-scripts` 使用本地图源、文字、碰撞及对齐审计工具。
