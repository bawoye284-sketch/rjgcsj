# 训练与评估样本重叠演示

本实验按作业演示要求，主动将部分原评估集样本及其标签加入训练，观察报告分数随样本重叠比例的变化。**这是有信息泄露的演示评估，不能当作独立测试或新患者预测性能。** 原数据标签、原独立划分、在线模型和既有性能报告均保留。

五个病种分别训练二分类 ExtraTrees 模型，不是五选一分类。每个病种仍使用原来的全部评估对象；依次将其中约 0%、25%、50%、75%、100% 的人加入原开发集。按正负标签分别固定随机顺序，保证不同重叠比例下的纳入集合嵌套。报告记录实际人数和实际比例，不修改标签、不人工填写分数、不按评估效果选择随机种子。阈值固定为0.5。

默认展示75%重叠实验。原模型与ExtraTrees算法不同，不能将二者所有差异归因于信息泄露；相同算法不同设置的全部过程指标保存在原始CSV中。100%为训练内回代演示。

当前课程演示继续使用全部原评估对象计算指标，包括其中参加过训练的记录，每个病种内每人只统计一次。五病种评估人数依次为171、360、366、344、367；不把统计范围缩减为剩余未参加训练的人员。现有模型权重和0.5分类阈值保持不变。

汇报用 `presentation_summary.csv`、`presentation_notes.md` 和 HTML 汇总表集中展示病种、人数与模型指标，不展开比例及过程对照列；统一标注“演示集评估（非独立测试）”。完整实验设置、逐人划分和过程指标仍保存在本说明、运行清单和原始指标文件中，保证结果可复现。

从项目根目录运行：

```powershell
& .\chronic-disease\.venv\Scripts\python.exe -B .\chronic-disease\experiments\overlap-demo\run_experiment.py
```

每次运行新建独立版本目录，包含 `data/` 数据快照与划分清单、`models/` 模型权重、`reports/` 指标/预测/图表/HTML汇报页。不会修改活动模型指针或接入前后端。若只重新绘图，使用 `plot_report.py --run <本次运行目录>`；有图形质量工具时可传 `--qa-scripts <工具目录>`。

所有图表统一放在每次运行的 `reports/模型性能图表/` 文件夹，使用带编号的中文名称，例如 `01_准确率对比.png`、`08_高血压混淆矩阵.png`。每张图同时提供PNG、PDF、SVG三种格式；报告可点击对应格式下载。校验记录保存在旁边的 `reports/figure_qa/`，不混入图表文件夹。

图中的标题、坐标轴、图例、病种名称和脚注均为中文，保留ROC、AUC、AP、F1等常用指标缩写。绘图自动选择微软雅黑、黑体或思源黑体；找不到中文字体时明确报错，避免导出缺字方框。

输出包括准确率、平衡准确率、精确率、召回率、特异度、F1、MCC、ROC-AUC、PR-AUC、Brier分数、对数损失、分类报告和完整混淆矩阵。另保存未参加训练的评估子集指标，帮助区分记住样本和预测新样本。全阴性基线用于说明类别不平衡的影响。每条预测记录是否参加过训练，可逐行核查。

绘图约定：图表回答“当前五病种模型在课程演示评估中的各项表现如何”。使用默认版本的真实预测与训练拟合指标；权重、评估人员和分类阈值均不改变。样式沿用项目配色与中文字体，统计逻辑按训练拟合和全部演示评估人员分别映射，不将其写成独立测试集。准确率、平衡准确率对比用于展示拟合与演示评估表现，样本规模和发病事件图说明统计基础，热力图、ROC、PR及五病种混淆矩阵展示完整评估结果。展示页不再绘制比例变化和实验过程对照曲线，图内不展开具体比例，图题仅保留图表名称，详细评估说明放在报告中。

图形类型为独立单绘图区的定量图，Python / Matplotlib绘制，常规图7.2×4.8英寸、混淆矩阵3.5×3.8英寸。白底、至少8pt中文文字，PNG为300dpi，PDF/SVG文字可编辑；课程汇报不要求TIFF。所有计数来自原始记录，每病种内每人只计算一次。比例为单次固定模型的点估计，不提供具有独立泛化含义的置信区间。图源、PDF文字、碰撞及人工视觉检查记录另存于figure_qa。

图中文字采用精简版：保留标题、坐标、图例及数值；ROC和PR图例直接注明AUC／AP，事件图只解释柱顶人数，混淆矩阵只解释人数与行占比。图题仅展示图表名称，不再添加“课程演示”后缀，也不在图片底部重复评估性质说明；非独立测试的详细说明、权重、阈值、划分及方法细节保留在报告和运行记录中。
