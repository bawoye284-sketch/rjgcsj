# 2. 在线风险评估服务

这个目录只负责 **加载已训练模型并提供预测接口**。

它不训练模型，也不包含 Vue 页面。

运行：

```powershell
& .\.venv\Scripts\python.exe -m pip install -r .\risk-service\requirements.txt
Set-Location .\risk-service
& ..\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8001
```

上述命令从项目根目录开始执行；也可在安装依赖后运行 `02_start_risk_service.bat`。

检查：

`GET http://127.0.0.1:8001/health`

预测：

`POST http://127.0.0.1:8001/predict`

在线评估包含两部分，并保留实测单项严重异常的安全警报：

1. 五项综合分实验模型：用呼吸率、血氧、收缩压、心率、体温及年龄、性别、BMI、舒张压，预测后续一天五项指标的代表状态综合分是否达到 5 分。分段参考 NEWS2，但不含吸氧和意识状态，不能称作完整 NEWS2。
2. 个人近期变化：比较本次测量与至少三次既往记录。模型和近期变化都触发预警时，上调综合等级；任一项触发时提示关注。实测单项严重异常不会被模型结果抵消。

训练数据来自住院重症病例，社区老人效果尚未验证。训练只使用缺测也不会改变五项综合分预警结论的标签；指标输入的缺失值由仅在训练集拟合的填补器估算，同时保留缺失标记。估算值不写回原始测量，资料不完整时系统不能凭估算值给出“正常”结论。

训练程序和在线服务被故意分开。上线时只需要部署这个目录中的模型服务。
