# 训练与演示说明

## 一、当前模型如何训练

1. 在 PyCharm 中打开项目，选择项目内的 Python 虚拟环境，并确认已安装训练所需依赖。
2. 运行[五项综合分训练程序](../model-training/train_five_score_model.py)。平时打开网站不需要重新训练。
3. 原数据按人员划分为训练 / 验证 / 测试。新标签参考后续一天五项数值指标的代表值综合分是否达到 5 分；仅保留缺测不影响结论的 445 / 82 / 91 人。它不是完整 NEWS2 或临床健康标签。
4. 缺失的呼吸频率用训练集拟合的近邻方法估算，血氧及其余缺失数值用训练集中位数填补；保留缺失标记，不改写原始记录。训练结束后查看正确率、召回率和精确率；这些数值仅反映替代标签，不能当作社区老人健康诊断准确率。

详细训练命令、数据处理和输出位置见[训练模块说明](../model-training/README.md)。

## 二、系统怎样判断风险

页面综合**模型预警值**与**个人近期变化**。任一部分达到预警条件显示“关注”，两部分都达到预警条件显示“高风险”；实测五项指标的严重异常及严重血压警报还会单独提示。没有足够历史时仍可参考模型；本次数据不完整时可以估算模型值，但不能凭估算值显示“正常”。

该模型的训练目标是未来五项指标的代表状态综合分进入预警区间，**不包含吸氧和意识状态**。综合分按未来一天各项实测值的中位数计算，并非同一时刻的正式 NEWS2 总分。页面不显示总分、各项得分或缺失项清单。“正常”只表示系统未触发预警，**不等于医学上的健康证明**；住院重症数据训练的模型在社区老人中尚未验证。

## 三、演示模式包含什么

演示模式使用本机数据库，**不需要 MySQL**。它预置了老人、医生、管理员账号，以及多条健康测量、资讯和咨询记录；操作产生的数据可在本机保存。

- **老人端**：查看资讯、记录身体数据及曲线、填写风险档案、查看评估结果、发起医生咨询。
- **医生端**：处理患者咨询；按患者查看身体数据、历史曲线和最近风险评估。
- **管理员端**：管理用户、医生、资讯、健康记录等业务数据。

演示时仍需分别启动 Python 风险服务、Java 后端和网页前端，顺序见[Windows 运行说明](RUN_WINDOWS.md)。调用外部智能问答服务的功能还需要单独配置接口，不能仅靠本地演示数据库运行。
